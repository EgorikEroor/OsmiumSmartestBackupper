# About 
OsmiumSmartestBackupper - is a lightweight context menu utility designed to simplify data archiving. With a single click, it creates a compressed backup of the selected file or folder, safely deletes the original to reclaim disk space, and provides a quick way to restore your data at any time.
# Features
* **Context Menu Integration:** Archive or restore files instantly via the right-click menu.
* **Space-Saving:** Automatically deletes original files after successful backup.
* **One-Click Restore:** Bring your files back whenever you need them.
# Installation
1. Download the latest release from the [Releases](https://github.com/EgorikEroor/OsmiumSmartestBackupper/releases) page.
2. Run the installer (`OSB_Setup_v_x64.exe`).
# Usage
### Delete and create backup
1. Right-click on any file or folder.
2. Select **"Delete & Back Up"**.
### Restoring data
1. Left-click the Start menu.
2. Left-click the **"OsmiumSmartestBackupper"** shortcut.
3. Left-click on the data.
4. Select **"Restore"**.
5. Select a folder.
# System Requirements
* Windows 10 / 11 (x64)
